# Accessibility mode

Per-device settings for contrast, text size, reading comfort, focus, target size, motion and shortcuts, plus screen reader and keyboard plumbing shared by every screen.

## Files Covered

| File | Purpose |
|------|---------|
| `settings.ts` | `A11ySettings`, `sanitize`, `toAttributes`, load/save (`ff.a11y.v1` in localStorage), tiny store (`getSettings`, `subscribe`, `updateSettings`) |
| `keyboard.ts` | `nextRadioIndex`, `isTypingTarget`, `shortcutKey`, `installRadioGroupKeys` |
| `announce.ts` | `announce(text)`: one polite live region for the whole app |
| `index.ts` | Applies saved settings before first paint and installs radio-group arrow keys; re-exports the above |
| `a11y.css` | All visual modes, keyed off `<html>` data attributes; skip link and dialog styles |
| `ui/AccessibilityButton.tsx` | Settings `<dialog>` (`AccessibilityDialog`, opened from the player menu in `src/nav`), `useA11yActiveCount`, and a standalone button |
| `ui/SkipLink.tsx` | "Skip to main content" link, first tab stop |
| `ui/hooks.ts` | `useA11ySettings`, `useFocusOnChange` (focus the new screen's heading), `useShortcuts` |
| `a11y.test.ts` | Settings and keyboard tests |

## How it works

- Each setting maps to an attribute on `<html>`: `data-contrast="high"`, `data-easy-read`, `data-focus="strong"`, `data-targets="large"`, `data-motion="reduce"`. Text size sets the root `font-size` (100/115/130/150%), so every rem size scales. Defaults set nothing, so the normal look is untouched.
- High contrast overrides the global tokens (`--bg`, `--ink`, `--accent`…) and the dice `--ff-*` tokens, with a light and a dark palette following the OS scheme. Screens that use the tokens get it for free; hard-coded colors need a rule in `a11y.css`.
- `prefers-reduced-motion` is always honoured; the setting forces it on.
- Keyboard: any `[role=radio]` inside `[role=radiogroup]` gets arrow/Home/End for free. Shortcuts are bare keys (c, b, d, p, a), ignored while typing or with Ctrl/Alt/Meta, and can be switched off (WCAG 2.1.4).
- Screen readers: `App` moves focus to the new screen's first h1/h2 on navigation; the sheet calls `announce()` for every change and undo.

## Adding to a screen

- Use the tokens from `index.css` rather than fixed colors, and rem for font sizes.
- Group exclusive choices as `role="radiogroup"` + `role="radio"` buttons; keys come for free.
- Call `announce()` from `src/a11y` when an action changes something not in focus.
