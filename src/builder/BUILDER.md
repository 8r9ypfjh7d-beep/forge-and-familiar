# Character builder

Seven-step wizard that turns choices into a `CharacterDraft`, then `createCharacter()` makes the saved character at full HP with its starting kit equipped.

## Files Covered

| File | Purpose |
|------|---------|
| `Builder.tsx` | Wizard shell, step navigation, `emptyDraft()`; `EditCharacter` loads a saved character into it |
| `edit.ts` | `draftFrom()`, `applyEdit()`, `startingGearChanged()`: editing a saved character |
| `CustomSubclassForm.tsx` | The player's own subclass editor (Custom chip in the subclass picker) |
| `steps.tsx` | Step components: Race (+ Dragonborn ancestry), Class (+ subclass), Abilities (+ ASI or feat), Background & skills (+ custom background, languages, tools), Equipment (SRD kit choices), Details |
| `ClassPicks.tsx` | Class multi-picks: Expertise / Primal Knowledge skill chips (Background & skills step) and Weapon Mastery weapon chips (Equipment step). Off-list chips are dimmed and only warn |
| `SpellsStep.tsx` | Spells step: per spellcasting class the cantrips and known/prepared/spellbook spells with counters, subclass always-prepared spells, race spells, and picks from spell feats (Magic Initiate) and the High Elf cantrip |
| `validate.ts` | `stepIssues()` per step (missing picks; they block Create/Save only) and `stepWarnings()` (off-book choices, shown as ⚠ notes, never block) |
| `ProficiencyPick.tsx` | `PickOrWrite` select with grouped options plus "✎ Write your own…" (opens a text box); `useLanguageGroups()` / `useToolGroups()` build the language and tool groups |
| `Summary.tsx` | Live preview panel using `derive()` |
| `ClassOptionPicker.tsx` | Eldritch Invocations and 2014 Pact Boon on the Class step: count by level, ⚠ on unmet prerequisites (pickable anyway), why? line per pick, Origin feat or cantrip for 2024 repeatables, "Take again" |
| `MulticlassPicker.tsx` | Optional extra classes on the Class step: prerequisites, proficiencies gained, caster-level math |
| `builder.css` | Builder-only styles, on the Liquid Glass standard (`src/design/DESIGN.md`) |
| `Why.tsx`, `why.css` | "why?" button (topic or any title/text, optional capsule label), `Explain` (the picked option's line) and `ExplainList` (name + line per feature, trait, language, tool) |
| `FeatPicker.tsx` | `FeatSelect` (every feat of the edition grouped by kind, plus "Make your own") and `FeatDetails` (our explanation, book, localized prerequisites, unmet-prerequisite warning) for ASI slots and the 2024 Human's Origin feat |
| `FeatEditor.tsx` | `FeatMechanics` (every effect a feat can have: +1 pick with optional save, fixed bonuses, skill picks, uses, armor/weapon training, all inventory `EffectsEditor` effects) and `CustomFeatForm`; Homebrew's feat editor reuses `FeatMechanics` |
| `why.ts` | "why?" topic ids, `explainKey(kind, id)` and `pitchKey()`; topic text is in `i18n/locales/en.ts`, option explanations in `i18n/locales/explain.en.ts` / `explain.he.ts` |
| `validate.test.ts` | Validation tests |
| `Shop.tsx` | Equipment step shop: SRD item library of the character's edition, search, item-type shelves, cart with budget |
| `shop.ts` | Pure shop helpers: `costCp`, `shopItem` (library item → engine id or embedded item), `changePurchase`, `coinText` |
| `shop.test.ts` | Prices, cart, engine ids, over-budget warning, editing purchases |
| `kit.ts` | `groupKitItems()`: repeated kit items shown once with a count (Javelin ×10) |
| `kit.test.ts` | Kit item grouping |
| `edit.test.ts` | Editing keeps play state and gear |
| `why.test.ts` | Every step, option and SRD entry (both editions) has an explanation |
| `style.test.ts` | Builder, "why?" and level history CSS use logical properties and glass tokens only |

## Notes

- Look: the step card and summary are `.glass`; tiles inside (race/class choices, stats, kit choices) are thin glass with the lens for the selected one. Buttons are `.glass-btn` (one `.prominent` per surface), picks are `.glass-chip`, the rules switch is `.glass-segmented`. On phones the step bar is one swipeable row that keeps the current step in view. The "why?" bubble is a `.glass-sheet`.

- Rules: the Race step starts with a 2014 / 2024 switch (`rulesEdition`). Switching clears race, background, skills, languages, tools, ASIs, gear picks and class choices; classes keep their levels and drop their subclass. New characters default to 2014.
- 2024: species show traits only; a Human picks an Origin feat. The Abilities step picks the background; its +2/+1 or +1/+1/+1 go on any ability from the table's Background column (`BackgroundBonusPick`). The background's three abilities are the suggestion (bold, plus a "Use the suggestion" button); others warn. A new background keeps off-list picks and clears ones that followed the old list. The Class step asks for Fighting Style, Divine Order or Primal Order when the level unlocks it (`ClassChoices`). In 2014 it also asks for Fighting Style, Favored Enemy and Natural Explorer, and folds Tasha's optional features into a `<details>` section that is never required; lists over 8 options use a select. Every feat is listed; ones whose level or other prerequisites aren't met show a warning (Epic Boons at 19). Feats with a +1 choice ask for the ability. Skilled adds three picks of any skill. Gear choices show their coins; option B is coins only. No custom background in 2024.
- Metamagic (both editions, `MetamagicPicker.tsx`): a sorcerer's Class step lists every option for the edition (2014: PHB + Tasha's; 2024: PHB) plus homebrew ones, with cost and why? line. The heading shows picked of allowed (`metamagicCount`); more than allowed only warns. Picks go in `Character.classOptions`.

- Random: "Random character" above the step bar (new characters only), the dice next to the name and the backstory hook on Details come from `src/random` (see `RANDOM.md`).
- Ability methods: standard array (with "suggest for my class"; picking a value another ability holds swaps them), point buy (27), roll 4d6 (rolls 4d6-drop-lowest six times through the dice roller, so the rolls land in dice history; totals saved as `rolledScores`, assigned with selects that swap like the standard array via `assignRolled`; reroll any time, the why? tip says to ask the DM), manual entry (3–20). Unassigned standard scores are 0.
- Loose by design (decided 2026-10-30, Ziv: "don't limit the user"): blocks are only for picks not made yet. Steps open in any order and Next always works; Create/Save waits for every step and points at the first unfinished one. Off-book choices warn in `stepWarnings()`: 2024 background bonuses off the background's list, 2014 free +1 on the race's excluded ability (Half-Elf CHA), moved racial bonuses ("Move my racial bonuses", `racialBonusTargets`), swapped racial skills, languages or weapons on the Race step (Tasha's "Swap my racial proficiencies", `OriginSwapsPicker`, `originSwaps`), an ASI past 20 (the engine still caps), a feat before its usual level (listed as "Feat (level N+)"), skills off the class list, tools off a pick's list ("Other tools" group). Expertise in a skill you aren't proficient in (or off Scholar's list), a Primal Knowledge skill off the class list, and mastery weapons you aren't proficient with (ranged for a Barbarian) also only warn; missing class picks and masteries block.
- Changing race or class clears chosen skills, since the allowed picks change.
- Portraits are resized to 320px JPEG data URLs before saving.
- Starting equipment follows the SRD "(a) or (b)" choices (`ClassDef.equipmentChoices`); "any martial weapon" slots get a dropdown and a default.
- Races, subraces, subclasses and feats list SRD content plus every homebrew pack on the device, so content from books the group owns is entered once in Homebrew.
- Background "Custom background" is the PHB rule: any 2 skills, 2 tools or languages in any mix, a named feature. No background items; the class kit and 15 gp still apply.
- Subclass is required once a class reaches `subclassLevel`. The picker lists every official subclass (with its book and bonus spells) plus Custom, which opens `CustomSubclassForm.tsx`: name, description, features by level (text, uses with recharge, sheet effects through the inventory `EffectsEditor`), bonus spells, armor/weapon proficiencies, HP per level, unarmored AC and (warlock) Charisma pact weapon. A custom subclass needs a name. Each ASI slot (`asiLevels`) needs two +1s or a feat; going past 20 only warns.
- Subclass picks: under the chosen subclass, every pick list its features offer at the class level (`subclassPickLists`): Battle Master maneuvers, Arcane Shots, runes, elemental disciplines, Kensei weapons, totem animals, Storm Herald environment, Wild Heart aspect, Hunter picks, Beast Master companion, Land terrain, dragon ancestry, Divine Soul affinity, bonus skills and more. Chips toggle (`togglePick`; a one-pick list swaps), the count shows next to the title and each picked option gets its why? line. Too few or too many picks, or one below its level, only warn (`stepWarnings` 'class'). Changing the subclass drops the old list's picks (`stalePicks`).
- 2014 book backgrounds (`BOOK_BACKGROUNDS`) are grouped by book in the picker like the 2024 ones. Some let you pick skills from a short list (`Background.skillChoices`, e.g. Haunted One); `skillPicks` returns them as `bgCount`/`bgFrom` and they share `chosenSkills` with class picks.
- Language picks come from race, subrace and background (`languagePickCount`); tool picks from race and first class (`toolPickGroups`), in that order in `chosenTools`.
- Every language and tool pick (and the custom background's two picks) offers every official name, grouped, plus "✎ Write your own…": the typed name is saved as-is and explained as "written in by you". A tool pick shows its own list first, the rest under "Other tools: <kind>" (warns). Druidic or Thieves' Cant without a Druid or Rogue level warns (`builder.warn.secretLanguage`).
- Changing race clears language, tool and trait picks; changing the first class clears skills, tools, gear picks, ASIs, class choices, class picks and weapon masteries.
- Spells step (both editions, multiclass aware): numbers come from `spellAccess` (the sheet's), wizards fill a spellbook (6 + 2 per level) and prepare from it. Counts are guidance: under or over only shows a note, never blocks. The pool is the edition's library plus homebrew and imported packs. Picks save to `Character.spells`; non-class picks use `classId` `extra:<slot>:<list>` (see `spellbook/extra.ts`). Changing a class or feat drops picks it no longer covers (`keepValidSpells`).
- Starting gold: in 2014 the Equipment step offers "Class kit" or "Gold" (the class's d4s × 10, Monk 5d4): roll (src/dice), take the average or type an amount; gold drops the class and background gear. In 2024 the class kit's A/B/gold choice is in the kit choices and the background gets its own "items + coins / 50 gp" choice. Changing the first class or the rules edition goes back to the kit.
- Shop: every Equipment step lists the edition's SRD items with prices (free pack contents hidden). Buying adds a cart line (bundles like 20 arrows count once); the coins left go into the starting coins. Spending more than you have only warns (`stepWarnings`) and starts at 0 coins. Ammo, rations, rope and the crystal focus are bought under the engine's ids so the sheet's counters see them. Editing purchases counts as a starting-gear change: swapping gear also moves the coins.
- Not in the builder yet: Bard (Lore) / Ranger / Rogue extra skill and expertise picks, trinkets.
- Multiclass: `classes[0]` is the starting class (saves, skills, gear). Unmet prerequisites only warn (decided 2026-10-29: many tables allow it): once scores are set, the picker marks short classes with ⚠ and shows a translated note, and `derive().warnings` lists them in the summary. All picker text is in en + he (`builder.mc.*`).
- "why?" tips are for new players: one short, jargon-light paragraph each. Every option is explained: card stats (legend capsules), each race trait, subrace/lineage, class (`why.about.<id>` plus the `why.class.<id>` pitch), class and subclass feature up to the chosen level, subclass, Fighting Style/Order, ability, skill, background, language, tool, kit choice and alignment. Features and traits are keyed by name, artisan's tools, gaming sets and instruments share one line per group.
- Add SRD content to `rules/data/` and `why.test.ts` fails until its line is in `explain.en.ts`; `i18n.test.ts` then asks for the Hebrew in `explain.he.ts`. Homebrew has no line and shows "ask your DM".
- Editing: "Edit" on the character card or sheet header reopens the builder prefilled (`view: 'edit'`). Every step is reachable, Save works from any step once all steps pass, and Cancel asks before discarding changes.
- An edit keeps id, XP, notes, coins, inventory and play state. Current HP moves by the change in max HP (0 HP stays 0); slots, hit dice and resources are clamped by the sheet's `normalize()`. If the class kit or background gear changes, a checkbox (on by default) swaps the old starting gear for the new; other items stay.
- Saving an edit takes a "Before edit" level snapshot first, so Levels can roll it back. While editing, the Summary derives from the edited character, so AC uses its real gear.
